# 그림핑퐁 (가칭) — 기획 & 설계 문서

> 커플/친한 친구끼리 **매일 랜덤 주제로 그림을 그리고, 홈 화면 위젯으로 실시간 공유**하며 평생 소장하는 앱.
> iOS 전용 '핑퐁'의 컨셉을 Android ↔ iOS **크로스플랫폼**으로 프라이빗하게 재구현한다.

---

## 1. 추천 기술 스택과 이유

| 레이어 | 선택 | 이유 |
|---|---|---|
| **프론트엔드 (앱)** | **Flutter (Dart)** | 단일 코드베이스로 iOS/Android 동시 지원. `CustomPaint` 기반 캔버스가 60fps로 부드럽고, **`home_widget` 패키지**가 양 OS 위젯 브리지를 공식 지원해 위젯 구현이 RN보다 매끄럽다. 구형 기기 호환 우수(아래 참고). |
| **백엔드 / 인증** | **Firebase Authentication** | 이메일/익명/소셜 로그인. 커플 2인 페어링만 필요하므로 가볍게. 서버 운영 부담 0. |
| **DB (실시간 동기화)** | **Cloud Firestore** | "상대가 그림 보내면 위젯 실시간 갱신" 요구에 맞는 실시간 리스너 제공. 오프라인 캐시 내장. 날짜/주제별 쿼리 용이. |
| **이미지 저장소** | **Firebase Storage** | 고화질 PNG 원본 보관(평생 아카이빙). Firestore엔 메타데이터(주제, 날짜, 썸네일 URL)만 저장. |
| **푸시 / 매일 주제 배포** | **Cloud Functions + FCM(푸시) + Firestore 스케줄** | 매일 오전 8시 Scheduled Function이 그날의 랜덤 주제를 두 사람의 공유 문서에 기록 → 동일 주제 동기화 보장 + 푸시 알림. |
| **위젯 구현 방식** | **Flutter `home_widget` + 네이티브 위젯** | 데이터 전달은 `home_widget`로, 위젯 UI 자체는 OS 네이티브(아래)로 구현. |
| **로컬 갤러리 저장** | **`image_gallery_saver` / `saver_gallery`** | 그린 그림을 기기 사진첩에 PNG로 즉시 저장. |

### 위젯은 결국 네이티브가 필요하다 (중요)
홈 화면 위젯은 Flutter UI를 그대로 못 띄운다. OS별 네이티브 위젯 프레임워크로 그려야 한다:
- **iOS**: **WidgetKit + SwiftUI** (iOS 14+)
- **Android**: **AppWidgetProvider + RemoteViews** 또는 **Jetpack Glance**

`home_widget` 패키지가 Flutter ↔ 네이티브 위젯 사이 **데이터 공유(이미지 경로/텍스트 전달)와 위젯 갱신 트리거**를 담당한다.

### 하위 호환성 최적화 (요구사항 1)
| 항목 | 권장 최소 버전 | 비고 |
|---|---|---|
| Android `minSdkVersion` | **21 (Android 5.0 Lollipop)** | 전체 기기 99%+ 커버. Firebase/Flutter 모두 지원. |
| iOS Deployment Target | **12.0** (앱 본체) | 단, **홈 위젯 기능은 iOS 14+** (WidgetKit 제약). iOS 12~13 사용자는 앱은 쓰되 위젯만 비활성. |
| Flutter | 안정 채널 최신 + null-safety | |

- 캔버스는 무거운 라이브러리 없이 `CustomPaint`로 경량 구현 → 저사양 기기에서도 부드럽게.
- 이미지 업로드는 WebP/적정 해상도로 압축, 원본은 Storage에 별도 보관.

## 2. 화면별 UI/UX 컴포넌트 구조

### 앱 전체 내비게이션
```
BottomNavigationBar (3탭)
├── 🏠 오늘 (TodayScreen)      : 오늘의 주제 + 그리기 진입 + 상대 그림 미리보기
├── ✏️ 그리기 (CanvasScreen)   : 메인 캔버스
└── 🖼️ 히스토리 (GalleryScreen): 날짜/주제별 아카이브
```

### 2-1. 캔버스 화면 (CanvasScreen)
```
Scaffold
├── AppBar
│   ├── 뒤로가기
│   ├── 오늘의 주제 칩  ("오늘 먹은 음식 그리기")
│   └── 저장/전송 버튼 (Send)
├── Body
│   └── DrawingCanvas (CustomPaint + GestureDetector)
│         ├── 그림 레이어 (List<Stroke>)
│         └── 현재 진행 중인 stroke
└── BottomToolbar
    ├── ColorPalette (색상 선택, 가로 스크롤)
    ├── BrushSizeSlider (펜 굵기)
    ├── EraserToggle (지우개)
    ├── UndoButton / RedoButton
    └── ClearButton (전체 지우기)

[액션]
- 갤러리에 저장: PNG로 렌더 → image_gallery_saver
- 전송: PNG → Firebase Storage 업로드 → Firestore 문서 생성 → 위젯 갱신
```

### 2-2. 히스토리 갤러리 탭 (GalleryScreen)
```
Scaffold
├── AppBar ("우리의 추억")
├── FilterBar
│   ├── 정렬 토글 (날짜순 / 주제순)
│   └── 작성자 필터 (나 / 상대 / 둘 다)
└── Body
    └── GroupedListView (월별 섹션 헤더)
          └── GridView (2~3열)
                └── DrawingCard
                      ├── Thumbnail (Storage URL, 캐시)
                      ├── 날짜 라벨
                      ├── 주제 라벨
                      └── 작성자 아바타
[탭 시] → DrawingDetailScreen (원본 풀스크린, 좌우 스와이프, 다운로드 버튼)
```

## 3. 데이터 모델 (Firestore)

```
couples/{coupleId}
  ├─ members: [uidA, uidB]
  └─ pairCode: "ABCD-1234"

couples/{coupleId}/dailyTopics/{yyyy-MM-dd}
  ├─ topic: "오늘 먹은 음식 그리기"
  └─ createdAt

couples/{coupleId}/drawings/{drawingId}
  ├─ authorUid
  ├─ date: "2026-05-31"
  ├─ topic: "오늘 먹은 음식 그리기"
  ├─ imageUrl   (Storage 원본)
  ├─ thumbUrl
  └─ createdAt
```

## 4. 핵심 플로우: "매일 주제 → 그리기 → 전송 → 위젯 갱신"
1. **08:00** Scheduled Cloud Function → 랜덤 주제 1개를 `dailyTopics/{today}`에 기록 + 두 사람에게 FCM 푸시.
2. 사용자가 **CanvasScreen**에서 그림 → "전송".
3. PNG를 **Storage 업로드** → `drawings` 문서 생성.
4. 상대 기기의 **Firestore 리스너**가 새 문서 감지 → 이미지 다운로드 → `home_widget`로 위젯에 경로 전달 → **위젯 갱신**.
5. 위젯 탭 → 딥링크 → **CanvasScreen** 진입.
